# Contributing

The Cacti is published as a portfolio project and a practical reference for people interested in local civic information systems.

Clear bug reports, thoughtful suggestions, and focused pull requests are welcome. The repository is not under an active support commitment, so a submission may remain open and may not be incorporated.

Before opening an issue:

1. Check that the problem occurs on the current `main` branch.
2. Describe what you expected, what happened, and the smallest set of steps that reproduces it.
3. Remove API keys, account details, private records, and runtime databases from screenshots or logs.

For a pull request, keep the change focused and explain how you verified it. Changes should preserve the project's neutral public-facing voice, trace generated material back to source documents, and avoid turning information about private residents into dossiers.
